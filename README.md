# Dizoo

**Logiciel de dictée vocale locale pour Windows 11 (64 bits).**

Dizoo permet de transcrire votre voix en texte directement sur votre ordinateur, grâce au moteur Whisper local.

## Fonctionnalités

- Dictée vocale avec raccourcis clavier.
- Transcription locale, utilisable hors connexion après installation du moteur.
- Sélection du microphone, vocabulaire personnalisé et historique temporaire.
- Interface native, personnalisable.
- Version installable et version portable.
- Vérification cryptographique des mises à jour.
